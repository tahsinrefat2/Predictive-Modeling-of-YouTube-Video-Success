# Predictive-Modeling-of-YouTube-Video-Success
This study presents a systematic methodology for
developing a machine learning pipeline to predict YouTube video
success based on various features. The process encompasses data
preprocessing, feature engineering, and model optimization.
Key steps include handling missing values, encoding categorical
variables, scaling features using Min-Max Scaling, and
performing outlier removal. Target variable binning and feature
selection were performed to enhance model performance and
interpretability. Several classifiers, including Decision Tree,
Random Forest, K-Nearest Neighbors, and XGBoost, were
evaluated using hyperparameter tuning and cross-validation.
Evaluation metrics such as accuracy, MAE, RMSE, R2, precision,
recall, and F1-score were used to identify the best-performing
model. The approach ensures robust and reliable predictions,
with results demonstrating the efficacy of the methodology in
handling diverse datasets. The novelty of this work lies in its
application to Bangla YouTube videos, a relatively unexplored
domain, and the use of a robust methodology incorporating
diverse machine learning techniques to optimize predictions for
this unique dataset. The Random Forest and XGBoost classifiers
emerged as the most effective, with the tuned Random Forest
achieving the highest performance metrics(86% accuracy),
emphasizing the significance of hyperparameter tuning and
ensemble approaches for complex datasets.
